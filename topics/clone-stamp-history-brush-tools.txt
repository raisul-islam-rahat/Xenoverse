Question: What is the difference between aligned and non-aligned cloning?
Answer: English: Aligned cloning keeps the source offset consistent as you stop and continue painting. Non-aligned cloning returns to the original sampled source each time a new stroke starts.

Question: How does the Clone Source panel manage several sources and transformations?
Answer: English: Clone Source panel stores multiple clone sources and controls source offset, scale, rotation, and overlay. Multiple clone sources let you switch between several saved sampling points. Clone source offset sets the horizontal and vertical distance between source and destination. Clone source scale resizes sampled content before it is painted. Clone source rotation rotates sampled content before it is painted. Clone overlay previews sampled source content over the destination for alignment.
Start with the default settings, change one control at a time, and inspect the result at both a useful zoom and the final viewing size.
Bangla: Clone Source panel multiple clone source রাখে এবং source offset, scale, rotation ও overlay নিয়ন্ত্রণ করে। Multiple clone sources কয়েকটি saved sampling point-এর মধ্যে switch করতে দেয়। Clone source offset source ও destination-এর horizontal ও vertical distance নির্ধারণ করে। Clone source scale sampled content paint হওয়ার আগে resize করে। Clone source rotation sampled content paint হওয়ার আগে rotate করে। Clone overlay alignment-এর জন্য destination-এর ওপর sampled source content preview করে।
default setting দিয়ে শুরু করুন, একবারে একটি control বদলান এবং useful zoom ও final viewing size—দুই জায়গায় result দেখুন।
