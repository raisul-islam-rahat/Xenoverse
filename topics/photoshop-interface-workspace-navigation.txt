Question: How do the Zoom, Hand, and Rotate View tools help me inspect an image?
Answer: English: Zoom tool changes how large the document appears on screen without changing its actual pixels. Hand tool pans the view when the document is larger than the visible window. Rotate View tool temporarily rotates the canvas view without rotating the image data.
Start with the default settings, change one control at a time, and inspect the result at both a useful zoom and the final viewing size.
Bangla: Zoom tool actual pixel না বদলে document screen-এ কত বড় দেখাবে তা পরিবর্তন করে। Hand tool document visible window-এর চেয়ে বড় হলে view সরায়। Rotate View tool image data না ঘুরিয়ে সাময়িকভাবে canvas view ঘোরায়।
