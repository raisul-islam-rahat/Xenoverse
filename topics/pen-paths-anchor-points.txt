Question: When should I use Pen, Curvature Pen, or Freeform Pen?
Answer: English: Pen tool creates precise straight and curved path segments using anchor points and direction handles. Curvature Pen tool creates and edits curves by placing points with simpler automatic curve handling. Freeform Pen tool draws a path by following a hand-drawn pointer movement.
Practise it through the chapter task: trace simple straight objects, curves, and a logo-like silhouette using as few anchor points as practical.
Bangla: Pen tool anchor point ও direction handle দিয়ে precise straight ও curved path segment তৈরি করে। Curvature Pen tool সহজ automatic curve handling-সহ point বসিয়ে curve তৈরি ও edit করে। Freeform Pen tool hand-drawn pointer movement অনুসরণ করে path আঁকে।
