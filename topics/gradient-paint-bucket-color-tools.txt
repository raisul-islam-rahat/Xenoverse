Question: How do Eyedropper sample size and Sample All Layers affect the sampled color?
Answer: English: Eyedropper tool samples a color from the image or supported on-screen source. Eyedropper sample size averages color from one pixel or a larger area to reduce accidental noise. Eyedropper Sample All Layers samples the visible composite instead of only the active layer.
Start with the default settings, change one control at a time, and inspect the result at both a useful zoom and the final viewing size.

Question: When should I use Linear, Radial, Angular, Reflected, or Diamond gradients?
Answer: English: Linear gradient changes color along a straight line. Radial gradient changes color outward from a center point in a circular form. Angular gradient sweeps color around a center point. Reflected gradient mirrors a linear gradient on both sides of its starting point. Diamond gradient expands color outward in a diamond-shaped pattern.
Choose it only when the image and desired result match the use described above; work on a copy, mask, or separate layer when possible.
Bangla: Linear gradient straight line বরাবর color পরিবর্তন করে। Radial gradient center point থেকে circular form-এ বাইরে color পরিবর্তন করে। Angular gradient center point-এর চারপাশে color sweep করে। Reflected gradient starting point-এর দুই পাশে linear gradient mirror করে। Diamond gradient diamond-shaped pattern-এ color বাইরে expand করে।
image ও desired result উপরের use-এর সঙ্গে match করলেই এটি choose করুন; সম্ভব হলে copy, mask বা separate layer-এ কাজ করুন।
