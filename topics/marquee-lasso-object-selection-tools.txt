Question: How do the four Marquee tools differ?
Answer: English: Rectangular Marquee tool makes rectangular selections and constrained square selections. Elliptical Marquee tool makes elliptical selections and constrained circular selections. Single Row Marquee tool selects a horizontal row that is one pixel high. Single Column Marquee tool selects a vertical column that is one pixel wide.
Test the options on duplicate layers with the same image, then compare control, edge quality, editability, and the final visible result.
Bangla: Rectangular Marquee tool rectangular selection ও constrained square selection তৈরি করে। Elliptical Marquee tool elliptical selection ও constrained circular selection তৈরি করে। Single Row Marquee tool এক pixel height-এর horizontal row select করে। Single Column Marquee tool এক pixel width-এর vertical column select করে।
একই image-এর duplicate layer-এ optionগুলো test করুন; তারপর control, edge quality, editability ও final visible result compare করুন।

Question: When should I use the Lasso, Polygonal Lasso, or Magnetic Lasso?
Answer: English: Lasso tool draws a freehand selection boundary. Polygonal Lasso tool builds a straight-edged selection by placing connected points. Magnetic Lasso tool tries to snap a selection boundary to visible high-contrast edges.
Choose it only when the image and desired result match the use described above; work on a copy, mask, or separate layer when possible.
Bangla: Lasso tool freehand selection boundary আঁকে। Polygonal Lasso tool connected point বসিয়ে straight-edged selection তৈরি করে। Magnetic Lasso tool selection boundary-কে visible high-contrast edge-এর সঙ্গে snap করার চেষ্টা করে।
image ও desired result উপরের use-এর সঙ্গে match করলেই এটি choose করুন; সম্ভব হলে copy, mask বা separate layer-এ কাজ করুন।

Test the options on duplicate layers with the same image, then compare control, edge quality, editability, and the final visible result.
