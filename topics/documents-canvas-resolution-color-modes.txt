Question: How should I choose width, height, unit, and orientation?
Answer: English: Width sets the horizontal size of a new document or image. Height sets the vertical size of a new document or image. Measurement unit decides whether dimensions are entered as pixels, inches, millimetres, centimetres, points, or another unit. Orientation describes whether a document is wider than tall, taller than wide, or square.
Start with the default settings, change one control at a time, and inspect the result at both a useful zoom and the final viewing size.
Bangla: Width নতুন document বা image-এর horizontal size নির্ধারণ করে। Height নতুন document বা image-এর vertical size নির্ধারণ করে। Measurement unit dimension pixel, inch, millimetre, centimetre, point বা অন্য unit-এ দেওয়া হবে তা নির্ধারণ করে। Orientation document আড়াআড়ি বেশি, লম্বালম্বি বেশি নাকি square তা বোঝায়।

Question: What is the document resolution setting, and how are PPI and DPI different?
Answer: English: Resolution setting connects pixel dimensions with a physical print size. PPI and DPI difference means PPI describes image pixels while DPI usually describes printer ink or toner dots.
Create one screen document in pixels and one print document in physical units; compare pixel dimensions, PPI, print size, and the printer's requested output settings.
Bangla: Resolution setting pixel dimension-এর সঙ্গে physical print size-এর সম্পর্ক তৈরি করে। PPI and DPI difference PPI image pixel বোঝায়, আর DPI সাধারণত printer-এর ink বা toner dot বোঝায়।
একটি screen document pixel-এ এবং একটি print document physical unit-এ তৈরি করুন; pixel dimension, PPI, print size ও printer-এর requested output setting compare করুন।

Question: When should I use RGB, and when might a printer require CMYK?
Answer: English: RGB mode uses red, green, and blue channels and is the normal choice for screens and many digital workflows. CMYK mode uses cyan, magenta, yellow, and black channels for many commercial print workflows.
Choose it only when the image and desired result match the use described above; work on a copy, mask, or separate layer when possible.
Bangla: RGB mode red, green ও blue channel ব্যবহার করে এবং screen ও অনেক digital workflow-এর সাধারণ choice। CMYK mode অনেক commercial print workflow-তে cyan, magenta, yellow ও black channel ব্যবহার করে।
image ও desired result উপরের use-এর সঙ্গে match করলেই এটি choose করুন; সম্ভব হলে copy, mask বা separate layer-এ কাজ করুন।

Question: What are Grayscale, Lab Color, and Bitmap modes used for?
Answer: English: Grayscale mode stores tonal information from black through gray to white without normal color channels. Lab Color mode separates lightness from two color-opponent channels and covers a wide color range. Bitmap mode represents each pixel with only black or white and requires special conversion conditions.
Locate the control in Photoshop, try it on a small safe file, and confirm exactly which layer, pixels, path, or output setting it changes.
Bangla: Grayscale mode সাধারণ color channel ছাড়া black থেকে gray হয়ে white পর্যন্ত tone সংরক্ষণ করে। Lab Color mode lightness-কে দুইটি color-opponent channel থেকে আলাদা রাখে এবং বড় color range ধারণ করে। Bitmap mode প্রতিটি pixel শুধু black বা white দিয়ে প্রকাশ করে এবং বিশেষ conversion condition প্রয়োজন।
Photoshop-এ controlটি খুঁজুন, small safe file-এ try করুন এবং এটি কোন layer, pixel, path বা output setting change করে তা confirm করুন।
