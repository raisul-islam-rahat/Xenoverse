Question: What is the difference between a vector mask and a clipping mask?
Answer: English: Vector mask controls visibility with an editable path for clean scalable edges. Clipping mask uses the transparency of a lower layer to limit an upper layer.
Test the options on duplicate layers with the same image, then compare control, edge quality, editability, and the final visible result.
Bangla: Vector mask clean scalable edge-এর জন্য editable path দিয়ে visibility নিয়ন্ত্রণ করে। Clipping mask নিচের layer-এর transparency দিয়ে উপরের layer সীমিত করে।
একই image-এর duplicate layer-এ optionগুলো test করুন; তারপর control, edge quality, editability ও final visible result compare করুন।

Question: When should I try Multiply, Screen, or Overlay modes?
Answer: English: Multiply blend mode usually darkens by combining layer values and is useful for many shadow or ink effects. Screen blend mode usually lightens and is useful for many bright or light-on-dark effects. Overlay blend mode combines contrast-increasing lightening and darkening behavior.
Choose it only when the image and desired result match the use described above; work on a copy, mask, or separate layer when possible.
Bangla: Multiply blend mode সাধারণত layer value combine করে dark করে এবং অনেক shadow বা ink effect-এ useful। Screen blend mode সাধারণত light করে এবং অনেক bright বা light-on-dark effect-এ useful। Overlay blend mode contrast বাড়ানো lightening ও darkening behavior combine করে।
image ও desired result উপরের use-এর সঙ্গে match করলেই এটি choose করুন; সম্ভব হলে copy, mask বা separate layer-এ কাজ করুন।
